## Real-World Data for Physical Intelligence

Origin Data Lab designs and operates **custom real-world data production programs for Physical AI, robotics, embodied AI, computer vision, and autonomous systems**.

We capture real people performing real tasks in real operational environments and transform those observations into structured datasets for model training, robot learning, validation, and evaluation.

Our work connects **field operations, multimodal capture, sensor synchronization, metadata engineering, technical validation, quality control, privacy processing, and structured delivery** in a single production workflow.

> **We do not start with generic video.**
>
> We start with the target task, environment, human behavior, viewpoint, sensor stack, metadata schema, acceptance criteria, and downstream model requirement.

## Multimodal Capture

Our capture architecture can combine multiple synchronized data streams according to project requirements.

| Visual | Motion & Sensors | Synchronization | Data Layer |
|---|---|---|---|
| RGB Video | Accelerometer | Video Timestamps | Session Metadata |
| Egocentric Video | Gyroscope | Sensor Timestamps | Device Metadata |
| Stereo Video | 6-Axis IMU | Cross-Modal Alignment | Validation Records |
| Multi-View Video | Audio | Session Timing | QC & Delivery Manifests |

**VIDEO + IMU + AUDIO + TIMESTAMPS + METADATA → VALIDATION → QC → STRUCTURED DELIVERY**

Capture configurations are adapted to project requirements rather than locked to a single hardware stack.

# What We Optimize For

### Task Relevance
Does the captured human behavior represent the target learning problem?

### Capture Integrity
Are viewpoint, visibility, sensors, timestamps, synchronization, and media technically valid?

### Operational Diversity
Does the dataset contain meaningful variation across people, tasks, objects, environments, and workflows?

### Metadata Integrity
Can every session be interpreted, validated, and traced downstream?

### Quality & Privacy
Does the data satisfy acceptance criteria, consent, privacy, and project-specific requirements?

### Engineering Readiness
Can the dataset enter the client's training or evaluation pipeline without unnecessary restructuring?
